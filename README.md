# youtrack-mcp-rs

MCP server for YouTrack — issues, articles, agile boards, and time tracking for AI coding agents.

> This project is not affiliated with or endorsed by JetBrains. YouTrack is a trademark of JetBrains s.r.o.

## Status

This crate is under active development as part of a Rust rewrite. It is currently a scaffold: build and test harness only, no MCP tools implemented yet.

## Building

```bash
cargo build
cargo test
```
